## The control plane for AI agents

NuraMesh makes AI agents prove their work: every action verified, approved where it matters, and always on the record.

- **[nuramesh](https://github.com/nuramesh/nuramesh)**: the open core, Apache 2.0
- **[Docs](https://docs.nuramesh.com)**: quickstart, concepts and guides
- **[Website](https://nuramesh.com)**: product and request access

Questions and ideas: [Discussions](https://github.com/nuramesh/nuramesh/discussions). Security reports: [SECURITY.md](https://github.com/nuramesh/.github/blob/main/SECURITY.md).
